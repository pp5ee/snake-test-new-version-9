# Snake Game

A classic Snake game with retro pixel aesthetics built with plain HTML/CSS/JS.

## Installation

1. Clone the repository
2. Open `index.html` in any modern web browser

No build steps or dependencies required.

## How to Play

- Use arrow keys (↑↓←→) to control the snake
- Eat the red food to grow and increase your score
- Avoid hitting walls or your own tail
- Press the "PLAY AGAIN" button to restart after game over

## Project Structure

```
.
├── index.html    # Main game page with canvas
├── style.css     # Retro pixel styling
├── script.js     # Game logic and localStorage handling
└── README.md     # This file
```

## Features

- Retro pixel visual aesthetic
- Arrow key controls with scroll prevention
- Score tracking during gameplay
- High score leaderboard (top 10) persisted in localStorage
- Game over screen with restart option

## Browser Compatibility

Works in all modern browsers that support HTML5 Canvas and localStorage.
